# Global Technology & Electrical Services — sitio web

Web corporativa de **https://globalchb.com** (Next.js 16 + Supabase, desplegada en Vercel).

- **Documentación de entrega:** [`docs/ENTREGA.md`](docs/ENTREGA.md): páginas, contenido editable desde el CRM, puesta en marcha del dominio, Google Search Console, variables de entorno y pendientes.
- **Formularios → CRM:** [`docs/crm-web-forms.md`](docs/crm-web-forms.md): qué escribe cada formulario en Supabase.

```bash
npm install
cp .env.example .env.local   # rellenar valores reales
npm run dev                  # http://localhost:3000
```
